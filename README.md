# Nexus Health Intel

Vite + React + TypeScript frontend for the Agentic Healthcare Intelligence demo. Deployed on **Vercel**; set `VITE_BACKEND_URL` to your FastAPI `/query` base URL (e.g. Hugging Face Space).

**Call / Email** use `tel:` and `mailto:` and need `phone` + `email` on each result from the backend. Redeploy the backend after re-ingest so metadata includes those fields.
